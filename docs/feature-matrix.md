# ModelForge 功能覆盖矩阵

本文件对应需求书中的模块编号，明确区分 **已实现 / 部分实现 / 未开放**。不完整能力不会在 UI 中被标记为完成。

状态说明：

- ✅ 已实现并有代码路径。
- ◐ 部分实现，边界在说明中。
- ○ 未开放 / 规划中。

### 架构兼容性诊断

| 模型 | 结论 |
|---|---|
| Llama / GPT2 / Qwen 标准文本模型 | 按 `convert_hf_to_gguf.py` 注册的架构精确匹配 |
| FishAudio S2-pro (`fish_qwen3_omni`) | `ARCH_UNSUPPORTED_CUSTOM`：自定义语音/多模态架构，需专用转换器与推理引擎，升级 llama.cpp 无法解决 |
| 其他含 `audio_*` / `vision_*` / `text_config` 的自定义架构 | 返回具体组件与相近已注册架构，避免误导为“升级即可解决” |
| 32 | 软件自动更新 | ✅ | GitHub Release 检查、语义化版本比较、更新说明展示、确认后下载 + SHA256SUMS 校验 + 解压，生成 Windows BAT / POSIX SH 脚本在进程退出后替换并重启；支持 `stable` / `nightly` / `auto` 三种更新通道（设置页可切换并持久化）；无更新、通道无发布、网络异常、版本解析失败、下载/校验/安装失败均有明确错误码。 |
| 33 | 图形化目录与文件选择 | ✅ | 设置页目录/文件路径、模型导入、转换输出目录与监控目录接入图形化选择器：位置快捷入口、懒加载展开/折叠、上一级与路径直达、当前选中路径展示、确认/取消；文件模式支持选中文件后校验并回填。后端 `/api/v1/fs/roots`、`/api/v1/fs/list`（`files=true` 返回文件）、`/api/v1/fs/file` 只读枚举与校验，覆盖不存在、非目录/非文件、权限不足、条目过多等状态并给出明确错误提示。 |

## 已验证的真实链路

- Windows 11
- 模型：`hf-internal-testing/tiny-random-LlamaForCausalLM`
- 输入：1,032,272 参数，21 张量
- 输出：Q4_K_M GGUF，2,789,056 字节
- 验证：GGUF v3，33 个元数据字段，llama-cli 深度加载验证通过
- 推理：llama-cli exit 0
- 基准：llama-bench 正常产出 prompt 与 generation 两组指标
- 任务取消：运行中进程终止，状态 CANCELED
- CLI 与 Web 服务并存：调度锁防止重复执行；CLI 任务由持有调度锁的进程执行
